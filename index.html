BackOffice

BackOffice is a private back-office tool for a one-person consulting practice: clients, rates, proposals, time and invoices. It is not a public service and has no sign-ups.

How it works

  • It runs only on its owner's own computer and listens only on that computer (127.0.0.1). Nothing is hosted on the internet.
  • It keeps its records in a database on that computer.
  • It connects to its owner's Google Drive to store backup copies of that database, using Google's drive.file permission: it can see and change only the files it created itself, never anything else in the Drive.
  • It never sends email or messages and never shares data with anyone.
