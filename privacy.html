BackOffice privacy policy

Effective 11 October 2026

BackOffice is a private tool used by one person, its owner, on their own computer. This page describes what it does with Google user data.

What Google data it accesses

BackOffice asks Google for one permission only: https://www.googleapis.com/auth/drive.file. With it, the app can create files in the signed-in user's Google Drive and see, change or delete only those files. It cannot see any other file in the Drive. It does not ask for email, contacts, calendar or any other Google data.

How it uses that data

The app uploads backup copies of its own database, and a small description file for each, to a folder it creates in the user's Drive, then checks that each upload arrived intact. That is the only use.

Where data is stored

  • The app's records stay in a database on the user's own computer.
  • The backups are stored in the user's own Google Drive.
  • The sign-in token Google issues is stored on the user's computer, encrypted with Windows' Data Protection API so only that Windows account can read it.

The app has no server of its own. No data is sent to the developer or to anyone else.

Sharing

BackOffice does not share, sell or transfer Google user data to anyone, does not use it for advertising, and does not use it to train AI or machine-learning models. Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Access can be removed at any time at myaccount.google.com/permissions. The backup files can be deleted from Google Drive like any other file, and the local data is removed by deleting the app's data folder on the computer.

Contact

Questions about this policy can go to the support email shown on Google's sign-in screen for BackOffice.
